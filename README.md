# Automated Exam and Lecture Timetable System

A web-based system for managing and automating university examination and lecture timetables.

## Project Overview

The system aims to simplify university timetable management by supporting timetable generation, venue allocation, timetable validation, and user management.

## Project Components

- **Frontend:** User interface for the system.
- **Backend:** Application logic and APIs.
- **Database:** Persistent storage using PostgreSQL.
- **Timetable Generation:** Automated generation of examination and lecture timetables.
- **Timetable Validation:** Validation of timetable constraints and conflicts.
- **Venue Allocation:** Allocation of suitable venues based on capacity and availability.
- **User Management:** Authentication and role-based access.

## Main Users

- Admin / Timetabling Officer
- Lecturer
- Student
